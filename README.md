# Список покупок — HTML-приложение («Чёрный лак»)

Работает без интернета, данные хранятся в самом телефоне (localStorage). Сборка не нужна — это обычные файлы.

- `index.html`, `app.css` — страница и стиль «Чёрный лак».
- `app.js` — экраны: «Списки», список по отделам, добавление с подсказками, долгое нажатие («Не было», изменить, перенести, удалить), «Обычный набор», настройки (акцент, блики от наклона).
- `store.js` — списки, пункты, история покупок, подсказки, «Обычный набор».
- `data.js` — отделы магазина и словарь «слово → отдел», подсказки по умолчанию.
- `lion.js`, `lion-data.js` — гранёный лев и свет (мышь или наклон телефона).
- `sw.js`, `manifest.webmanifest`, `icons/` — офлайн и иконка «На экран Домой».

Проверить на компьютере: `python3 -m http.server 8765` в этой папке и открыть http://localhost:8765.
На телефон с офлайном — только через HTTPS-хостинг (например, GitHub Pages): Safari → «Поделиться» → «На экран Домой».
